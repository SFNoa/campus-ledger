# 我的账本 · campus-ledger

> Android 记账 App：**自动同步校园卡流水**，**读微信/支付宝的支付通知自动记账**。
> 纯本机运行 —— 没有服务器，不上传任何数据。

**Kotlin** · **Jetpack Compose** · **Material 3** · 最低 Android 8.0

[功能](#功能) · [截图](#截图) · [下载与安装](#下载与安装) · [自己编译](#自己编译) · [隐私](#隐私) · [开发文档](docs/DEVLOG.md)

## 它解决什么问题

| 日常的麻烦 | 这个 App 的做法 |
|---|---|
| 校园卡花了多少，要一笔笔手抄 | 绑定后**自动同步**余额与消费流水 |
| 微信/支付宝付完就忘了记 | 读支付通知，**本地解析金额和商户**后自动记一笔 |
| 记账 App 都要注册账号、数据传云端 | **只存本机**；连密码都是加盐哈希存的，原文不落盘 |
| 红包、转账、提现算进了支出，数字不对 | 内部转账**自动配对**；配不上的可手动标记，**不计入收支** |

## 功能

### 记账
- 底部三标签：**流水 / 资产 / 我的**
- 流水可按 **日 / 月 / 年** 分组；日期条上左右滑动就能换日期，**当前选中项居中**
- 每笔都能**改名**、**改分类**（两级分类：餐饮 → 食堂/外卖/饮品）
- 自动分类：认得出「广铁/中铁」是交通、「商户/商城」是购物、「超市/便利店」是日用品
- **待确认**的记录可以补录金额，不用删掉重记
- 批量管理：一次清理多条误抓的旧记录

### 自动记账（微信 / 支付宝）
- 监听支付通知，本地解析后入账（**只读这两个应用的通知**，内容不联网）
- **内部转账自动配对**：一手出一手进的两条自动抵消
- 配不上的（银行卡充值、提现、还款）可**手动标记为内部转账**
- 多个账户可混着记：校园卡、微信、支付宝，各自算各自的余额

### 校园卡同步
- 自动取回**余额**与**消费流水**，余额随流水自动增减
- 请求有**频率限制**，避免触发学校风控（详见[开发日志](docs/DEVLOG.md)）

### 官方账单导入（半自动）
- 支持 **CSV / XLSX / 加密 ZIP**（微信、支付宝导出的账单直接丢进来）
- 不写死行数和列位置，按**列名**映射，账单格式变了也不容易崩
- 三层去重：不会和已同步的流水重复

### 外观
- **三种底色**（半透明 / 纯白 / 雾灰 / 深青）× **六种主题色**，随你换
- 顶部轮换图可换成自己的照片；头像可上传

## 下载与安装

到 [Releases](../../releases) 下载最新 APK（约 2 MB）。

首次进入：**注册本机账号（可传头像）→ 权限教学 → 绑定中心**，每一步都能跳过。
不绑定任何东西也能当普通账本用。

## 自己编译

需要 **JDK 17** 与 **Android SDK 35**。

```bash
./gradlew assembleDebug        # 调试包
./gradlew testDebugUnitTest    # 315 项单元测试（JUnit4 + Robolectric）
./gradlew assembleRelease      # 正式包（需先配签名，见下）
```

正式包签名：在项目根目录建 `keystore.properties`（**已在 .gitignore 里，不要提交**）：

```properties
storeFile=keystore/你的.jks
storePassword=你的口令
keyAlias=你的别名
keyPassword=你的口令
```

没有这个文件时 release 包不会被签名（能编译但装不上），不会导致构建失败。

## 隐私

**没有服务器，数据只在这台手机上。**

- 通知使用权：只读微信/支付宝的支付通知，**本地解析**，原文不联网
- 校园卡凭据：**Android Keystore 的 AES 密钥**加密后存本机
- 本机账号密码：**加盐哈希**，原文不落盘
- 不收集任何统计、崩溃、设备信息；没有广告 SDK
- 卸载或清除数据 → 立即永久删除，作者这边没有副本

完整说明见 [隐私政策](PRIVACY.md)。

## 已知限制（如实说明）

- **数据库未加密**：本机账号的密码锁是界面层的保护，能 root 手机并物理接触的人可以读到数据。
  这是刻意的取舍 —— 见[隐私政策](PRIVACY.md)里的说明
- **小米/红米需要开自启动**：不然系统会拒绝绑定通知监听服务（App 里做了自检提示）
- **校园卡消费不会出现在微信/支付宝账单里**（那是卡内扣费），所以账单导入抓不到这部分
- 校园卡同步依赖学校系统的接口，**学校改版就会失效**
- 记账结果仅供参考，不作为财务或报销依据
