# v1.0

第一个公开版本。

## 下载

app-release.apk，大概 2 MB，已经签过名了，直接装。需要 Android 8.0 以上。

## 这个版本有什么

- 校园卡自动同步。中南大学实测过，余额和消费记录会自动进来
- 微信支付宝通知记账。读支付通知，本地解析金额和商户
- 内部转账自动配对。一手出一手进的两条自动抵消，配不上的可以手动标
- 账单导入。微信支付宝导出的 CSV、XLSX、加密 ZIP 都能导
- 两级自动分类。广铁认成交通，商户认成购物，食堂认成餐饮
- 四种底色、六种主题色，顶部图片和头像都能换

## 隐私

没有服务器，数据只在这台手机上。通知内容本地解析，不外传。校园卡密码用 Android Keystore 加密存着，本机账号的密码是加盐哈希。详细说明在 [隐私政策](https://github.com/SFNoa/campus-ledger/blob/main/PRIVACY.md)。

## 第一次打开

会让你注册一个本机账号，可以顺便传头像。然后讲一下权限，最后进绑定中心。每一步都能跳过。

小米和红米的用户注意一下：如果通知记账不工作，去设置里的应用管理找到我的账本，把自启动打开，省电策略设成无限制。MIUI 在 App 更新之后会拒绝绑定通知监听服务，App 里遇到这种情况会提示你。

## 已知的问题

数据库没加密，本机密码锁只挡界面，原因写在隐私政策里。

校园卡的消费不会出现在微信支付宝账单里，账单导入抓不到这部分。

学校系统改接口就会失效。
